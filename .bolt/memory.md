# Project memory

## Product intent & audience

- Web application with an admin login/sign-in area and contact information including email addresses.
- Next.js-based project developed and hosted via Bolt.

## Brand personality & voice

- Not yet established from available context.

## Visual design & UX direction

- Includes an admin sign-in screen with customizable sign-in text.
- Contact area displays at least two admin/contact email addresses.

## Decisions, constraints & rationale

- Framework: Next.js.
- Development environment: Bolt (StackBlitz); GitHub integration used for version control and pushing code.
- Bolt auto-handles commits/pushes once GitHub is connected; only the project owner can sync to GitHub.
- Live site changes require redeployment after code is pushed.
- Default branch expected to be `main`.
